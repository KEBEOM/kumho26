## 1. 마스터 프롬프트

> 앱 전체를 만들 때 AI에게 준 기준 프롬프트입니다. 이 프롬프트와 교수자 자료(starter 폴더, 기준데이터, 검산표)를 함께 주면 같은 구조의 앱을 다시 만들 수 있습니다.

```text
[역할]
너는 통계 교육용 웹앱을 만드는 Python/Streamlit 개발자다. 사용자는 앱 개발이 처음인 대학원생 팀이다.

[목표]
교수자가 준 starter 폴더(app.py, analysis.py, requirements.txt, sample.xlsx, tests/)를 바탕으로,
PC에서 실행하고 스마트폰 브라우저에서도 쓸 수 있는 "초보자용 통계분석 웹앱"을 완성하라.

[입력]
- 엑셀(.xlsx, .xls) 또는 CSV 업로드. CSV는 UTF-8/CP949 한글 인코딩을 자동 인식.
- 파일 없이도 시험할 수 있게 "예제 데이터"(교수자 기준데이터 36행, sample.xlsx 12행) 선택 제공.

[분석 메뉴 — 각각 사용자가 변수를 직접 선택]
0. 데이터 확인: 미리보기 20행, 열별 자료형·결측 수·고유값 수
1. 기초통계: n, 결측, 평균, 표준편차, 중앙값, 최소·최대, Q1, Q3, IQR, 왜도, 히스토그램, 범주형 빈도·비율
2. 정규성 검정: Shapiro-Wilk W·p, 왜도·첨도, Q-Q 그림
3. 상관분석: Pearson/Spearman 선택, APA 형식 상관표(아래 삼각형, 별표), 상관 히트맵, 쌍별 r·p·n
4. t검정: 독립표본(Levene 결과에 따라 Student/Welch 자동 안내, 3집단 이상이면 두 집단 선택),
   대응표본(사전-사후), 일표본, Cohen's d·Hedges' g, 평균차 95% CI
5. 교차분석: 교차표, 행 백분율, χ², Cramér's V, 기대빈도 5 미만 칸 20% 초과 경고, 2×2면 Fisher 정확검정, 표준화 잔차
6. 신뢰도: Cronbach's α, 표준화 α, 수정된 문항-총점 상관, 문항 삭제 시 α, 음의 문항-총점 상관으로 역문항 감지, 역코딩 기능
7. 단순회귀: Y 1개, X 1개 → 회귀식, R², 수정 R², F, B·SE·β·t·p·95% CI, 산점도+회귀선, 잔차 그래프
8. 다중회귀: Y 1개, X 여러 개 → 위 항목 + VIF(10 초과 시 경고)
9. 일원분산분석: 집단별 n·평균·SD, 분산분석표(SS, df, MS, F, p), η², ω², Levene 등분산 검정, Tukey HSD 사후검정
10. 이원분산분석: Type III 제곱합(효과 코딩), 부분 η², 칸 평균, 상호작용 그래프,
    상호작용이 유의하면 "주효과만 따로 해석하지 말라"는 주의 문구
11. 매개효과(X→M→Y): a, b, c, c', 간접효과 ab, Sobel 검정, 부트스트랩 95% CI(난수 고정), 경로 그림
12. 조절효과(Y ~ X + W + X×W): 상호작용 B·p, R², ΔR², 평균중심화 선택, 단순기울기(W 평균±1SD), 그래프
13. 기준값 검산: 교수자 기준결과와 앱 계산값을 자동 비교해 일치/불일치 표시
14. 보고서 내려받기: 각 분석 화면의 '📌 보고서에 추가' 버튼으로 담은 결과(표·해석·APA 문장)를
    HTML / Word(.doc) 한 파일로 저장

[공통 기능]
- APA 형식: 결과마다 APA 보고 문장(복사용), 사이드바 토글로 표를 APA 형식(소수 둘째 자리, p = .027)으로 전환
- 결측값 처리 선택: 분석할 때 제외(listwise) / 숫자형 평균 대체(채운 개수 안내)
- 예제 데이터 3종: 교수자 기준데이터, 가상 설문(120명, 리커트 5문항·역문항·결측 포함), sample.xlsx
- 제작자 표기 'by 2026 금오공대 빅데이터 8조'를 제목 아래·화면 맨 아래·보고서에 작게 표시

[해석 문장]
- 각 분석 결과 아래에 쉬운 한국어 해석 문장을 자동 생성하라.
- p값만으로 중요하다고 말하지 말고 효과크기(R², η², 부분 η²)를 함께 쓴다.
- 회귀·매개·조절은 "인과관계를 단정하지 않는다"는 문장을 반드시 넣는다.

[오류 처리 — 앱이 절대 멈추지 않게]
잘못된/손상된 파일, 빈 파일, 중복 열 이름, 결측, 표본 부족, 집단 1개, 사례 1개뿐인 집단, 빈 칸(요인 조합),
숫자 아닌 변수 선택, 같은 변수를 두 역할에 중복 선택, 값이 모두 같은 변수, 완전 다중공선성
→ 모두 쉬운 한국어 안내로 보여 준다. 예상하지 못한 오류도 화면에는 안내만, 상세 내용은 접어서 표시.

[화면]
- 스마트폰 기준(layout="centered"), 지표는 2개씩 줄바꿈, 표는 가로 스크롤.
- 사이드바에 "좁은 화면용 표(세로로 보기)" 토글.
- 그래프는 Streamlit 기본 차트 사용(한글 깨짐 없음, 모바일 반응형).
- 결과표마다 CSV 저장 버튼(엑셀 한글 깨짐 방지 utf-8-sig).

[코드 구조·제약]
- app.py = 화면, analysis.py = 계산. 계산 함수는 화면 코드 없이 테스트 가능해야 한다.
- 계산은 numpy·pandas·scipy만 사용(statsmodels·pingouin 없이 최소제곱법 직접 구현 → 설치 오류 감소).
- 결측은 선택한 변수 기준 listwise 제외, 실제 사용 사례 수를 화면에 표시.
- 교수자 기준결과(02_기준결과_검산표.md)와 모두 일치해야 하며, pytest로 자동 검산한다.

[산출물]
GitHub에 바로 올릴 수 있는 저장소 구조로 만든다(파일·폴더 이름은 영문):
app.py, analysis.py, requirements.txt, README.md, data/reference_data.xlsx, data/survey_sample.xlsx, data/sample.xlsx,
tests/test_analysis.py, tests/test_extra.py, tests/test_app.py(Streamlit AppTest), .streamlit/config.toml,
run_windows.bat, run_mac_linux.sh, .gitignore, .github/workflows/tests.yml(push마다 자동 테스트), docs/MASTER_PROMPT.md
README에는 실행 방법(PC·스마트폰·무료 서버 배포), 기능, 사용 라이브러리와 버전, 제한점, 자주 생기는 문제를 쓴다.

[작업 방식]
한 번에 한 기능씩 추가하고, 추가할 때마다 기준데이터로 검산한 뒤 다음 단계로 넘어간다.
```

## 2. 단계별 코딩 프롬프트

> 마스터 프롬프트를 실제 개발할 때 단계별로 나누어 요청한 프롬프트입니다. 교수자 제공 「주차별 AI 프롬프트」를 기반으로 팀 앱에 맞게 구체화했습니다.

### 1단계 — 실행·업로드 확인
```text
현재 starter 폴더의 app.py를 설명하고, 엑셀 업로드와 데이터 미리보기가 정상인지 확인하는 체크리스트를 만들어줘.
추가로 파일 없이도 시험할 수 있게 '예제 데이터 사용' 선택지를 넣고, 기준데이터는 data/reference_data.xlsx로 두고 불러오게 해줘.
CSV는 UTF-8과 CP949(한글 윈도우) 인코딩을 모두 읽을 수 있게 해줘.
```

### 2단계 — 기초통계
```text
숫자형 변수의 n, 결측, 평균, 표준편차, 중앙값, 최소·최대, Q1, Q3, IQR, 왜도를 보여줘.
변수를 골라 히스토그램(막대 개수 조절)을 보여 주고, 범주형 변수는 빈도와 비율(%) 표를 따로 보여줘.
숫자 열에 '결석' 같은 글자가 섞여 있으면 결측으로 처리하고 몇 개를 처리했는지 안내해줘.
수정 파일과 위치를 먼저 알려주고, 기준데이터 score의 평균 76.000, SD 8.135와 비교해 검산해줘.
```

### 3단계 — 단순·다중회귀
```text
단순회귀와 다중회귀를 추가해줘. Y 1개와 X 1개 이상을 선택하게 하고
R², 수정 R², F, B, SE, 표준화 β, t, p, 95% CI, 회귀식, 잔차 그래프, VIF를 표시해줘.
statsmodels 없이 numpy 최소제곱법으로 계산해줘.
표본 부족, 문자형 변수, 같은 변수 중복 선택, 값이 모두 같은 변수, 완전 다중공선성을 막아줘.
검산: score~study_time R²=0.0330, B=1.1089, p=0.288707 / score~study_time+pre_score R²=0.9349, 수정R²=0.9310
```

### 4단계 — 일원·이원분산분석
```text
일원·이원분산분석을 추가해줘.
일원: 집단별 n·평균·SD, 분산분석표, η²와 ω², Levene 등분산 검정, Tukey HSD 사후검정.
이원: Type III 제곱합(효과 코딩), 부분 η², 칸 평균표, 상호작용 그래프.
상호작용이 유의하면 해석 주의 문구를 표시해줘.
집단이 1개, 집단에 사례가 1개, 비어 있는 칸이 있으면 한국어로 안내해줘.
집단변수 목록에서 이름·ID처럼 행마다 값이 다른 열은 빼줘.
검산: 일원 F=14.0291, p=0.000039 / 이원 method F=266.3419, grade F=283.2311, 상호작용 F=8.2607
```

### 5단계 — 매개·조절효과
```text
단순 매개(X-M-Y)와 조절(X-W-Y)을 추가해줘.
매개: a, b, c, c', 간접효과 ab, Sobel 검정, 부트스트랩 95% CI(난수 고정, 반복 수 선택), 경로 그림.
조절: X×W 상호작용, ΔR², 평균중심화 선택, W 평균±1SD에서의 단순기울기와 그래프.
인과관계를 단정하지 않는 해석 문장을 사용해줘.
검산: a=0.8027, b=1.5300, c'=0.1383, ab=1.2282 / 상호작용 B=0.6786, R²=0.9743
```

### 6단계 — 오류 처리·스마트폰 화면
```text
잘못된 파일, 빈 파일, 결측, 표본 부족, 집단 1개, 숫자 아닌 변수 선택 때 앱이 멈추지 않고
쉬운 한국어 안내를 보여주게 해줘. 예상하지 못한 오류도 앱 전체가 멈추지 않게 감싸줘.
스마트폰 화면에서 표가 잘리지 않게 정리하고(가로 스크롤, 세로 보기 토글), 지표는 2개씩 보여줘.
결과표마다 CSV 저장 버튼을 넣어줘.
```

### 7단계 — 검산·문서화·배포
```text
기준데이터 결과와 앱 결과를 비교하는 '기준값 검산' 메뉴와 pytest 테스트를 만들어줘.
GitHub에 올리기 좋게 정리해줘: 한글 파일명은 영문으로, README.md, .gitignore,
push할 때마다 검산 테스트가 자동으로 도는 GitHub Actions, 모든 메뉴를 실제로 열어 보는 Streamlit AppTest 테스트.
README에 실행 방법(Windows/mac, 스마트폰, GitHub+Streamlit Community Cloud 무료 배포),
사용 라이브러리와 버전, 분석 제한점, 자주 생기는 문제를 넣어줘.
초보자도 더블클릭으로 실행할 수 있는 실행 파일(bat/sh)과 최종 점검 체크리스트도 만들어줘.
```

### 8단계 — 분석 기능 확장 (설문 분석 필수 기능)
```text
지금 앱에 설문 분석에 꼭 필요한 기능을 추가해줘. 한 메뉴씩 추가하고 매번 scipy 결과와 비교해 검산해줘.
1) 정규성 검정: Shapiro-Wilk, 왜도·첨도, Q-Q 그림
2) 상관분석: Pearson/Spearman, APA 상관표(별표), 히트맵(추가 설치 없이 Streamlit 내장 차트로)
3) t검정: 독립표본(Levene → Student/Welch 안내), 대응표본, 일표본, Cohen's d
4) 교차분석: χ², Cramér's V, 기대빈도 경고, 2×2면 Fisher 정확검정
5) 신뢰도: Cronbach α, 문항-총점 상관, 문항 삭제 시 α, 역문항 감지와 역코딩
시연용으로 개인정보 없는 가상 설문 데이터(리커트 문항, 역문항, 집단, 사전·사후 점수, 약간의 결측)도 만들어줘.
```

### 9단계 — 완성도 (보고서·APA·결측 처리)
```text
1) 각 분석 결과를 '보고서에 추가' 버튼으로 담고, 마지막에 HTML과 Word(.doc) 보고서 한 파일로 내려받게 해줘.
2) 결과마다 APA 보고 문장을 복사할 수 있게 보여 주고, 사이드바에서 표를 APA 형식으로 바꾸는 토글을 넣어줘.
3) 사이드바에서 결측값 처리를 '제외(listwise)'와 '평균 대체' 중에서 고를 수 있게 해줘.
4) 제작자 'by 2026 금오공대 빅데이터 8조'를 작게 추가해줘.
```

| # | 상황 | 원인 | 수정 |
|---|---|---|---|
| 1 | 숫자 열에 '결석' 같은 글자가 섞인 파일에서 빈도표가 멈춤 | 숫자와 글자를 함께 정렬하려다 TypeError | 값을 문자로 바꿔 정렬, 빈도표도 오류 보호 함수로 감쌈 |
| 2 | 일원분산분석에서 '이름' 열이 집단변수로 자동 선택됨 | 행마다 값이 다른 열도 집단 후보에 포함 | 고유값이 사례 수의 절반을 넘는 열은 제외, 문자형 열을 앞에 배치 |
| 3 | 해석 문장에 `p=< .001`처럼 어색한 표기 | p값 표기 함수 하나로 표·문장 모두 처리 | 문장용 `p < .001` / `p = 0.123` 표기 함수 분리 |
| 4 | 최신 Streamlit에서 경고가 날 수 있는 인자 | `use_container_width` 지원 종료 예정 | 해당 인자 제거(기본값으로 화면 폭에 맞춤) |

| 6 | Vercel 배포 가능 여부 검토 | Streamlit은 상시 실행 Python 서버+웹소켓 필요, Vercel은 요청 시에만 실행 | Streamlit Community Cloud 배포로 결정 |
| 7 | GitHub·배포 시 한글 파일명 문제 우려 | 한글 경로는 URL 인코딩·환경별 오류 가능 | 파일·폴더 이름을 영문으로 변경 (화면 표시는 한글 유지) |
| 8 | Streamlit Cloud 배포 시 'This branch does not exist' | GitHub 업로드 후 Commit을 하지 않아 브랜치가 아직 없음 | 업로드 후 Commit changes, Main file path를 `app.py`로 지정 |
| 9 | 기초통계·정규성 기본 선택에 `id` 열이 포함됨 | 숫자형이면 모두 기본 후보로 사용 | id·번호 같은 열은 기본 선택에서 제외 |
| 10 | t검정 문장에 `t(116.00)`처럼 자유도가 소수로 표시 | Student 자유도도 소수 형식으로 출력 | 정수면 정수로, Welch만 소수 둘째 자리로 표시 |

## 6. 한계와 개선할 점

- 회귀의 X는 숫자형만 지원 → 범주형 X 자동 더미 변환 추가 필요

- 결측 대체는 평균 대체만 지원(분산 과소추정 가능) → 다중대체(MI) 등으로 확장 가능
- 보고서에 그래프는 포함되지 않음(표·해석·APA 문장만) → 그래프 이미지 삽입으로 확장 가능
- 로지스틱 회귀·판별분석·요인분석 등 다변량 분석은 미지원 → 다음 확장 후보
