0. 가장 빠른 실행 (권장)
==================================================================
· Windows : 폴더 안의 「실행하기_Windows.bat」 더블클릭
· macOS/Linux : 터미널에서  bash 실행하기_mac_linux.sh

  → 잠시 뒤 브라우저에 http://localhost:8501 이 자동으로 열립니다.
  → 앱 화면에서 「예제 데이터 사용 → 기준데이터」를 고르면 파일 없이 바로 시험할 수 있습니다.
※ Python 3.10 이상이 설치되어 있어야 합니다 (설치 시 "Add python.exe to PATH" 체크).

1. 직접 명령어로 실행
==================================================================
Windows
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  streamlit run app.py

macOS/Linux
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  streamlit run app.py

브라우저에서 http://localhost:8501 을 엽니다.

==================================================================
2. 스마트폰에서 보기
==================================================================
(방법 A) 같은 Wi-Fi
  streamlit run app.py --server.address 0.0.0.0
  PC의 IP 확인: Windows는 명령창에서 ipconfig → "IPv4 주소"
  스마트폰 브라우저에서 http://(PC IP):8501   예) http://192.168.0.15:8501
  · 안 열리면: 같은 Wi-Fi인지, Windows 방화벽에서 Python 허용을 눌렀는지 확인
  · 학교 Wi-Fi는 기기 간 접속을 막는 경우가 많음 → 휴대폰 핫스팟에 PC를 연결하면 대부분 해결

(방법 B) 무료 서버에 올리기 — GitHub + Streamlit Community Cloud (선택)
  1) GitHub에 새 저장소(public)를 만들고 이 폴더의 파일을 모두 업로드
     (app.py, analysis.py, requirements.txt, data/, sample.xlsx, .streamlit/ 포함)
  2) https://share.streamlit.io 에 GitHub 계정으로 로그인 → "Create app"
  3) 저장소 선택, Main file path = app.py → Deploy
  4) 발급된 https://○○○.streamlit.app 주소를 스마트폰에서 열면 어디서나 사용 가능
  ※ 공개 저장소에는 개인정보가 담긴 데이터를 절대 올리지 마세요.

4. 기능
==================================================================
 0. 데이터 확인   미리보기, 열별 자료형·결측·고유값 수
 1. 기초통계     n, 결측, 평균, 표준편차, 중앙값, 최소·최대, Q1·Q3·IQR, 왜도,
                히스토그램, 범주형 빈도·비율표
 2. 단순회귀     회귀식, R², 수정 R², F, B·SE·β·t·p·95% CI, 산점도+회귀선, 잔차 그래프, 해석 문장
 3. 다중회귀     위 항목 + VIF(다중공선성) 경고
 4. 일원분산분석  집단별 n·평균·SD, 분산분석표, η²·ω², Levene 등분산 검정, Tukey HSD 사후검정
 5. 이원분산분석  Type III 분산분석표, 부분 η², 칸 평균, 상호작용 그래프, 상호작용 유의 시 해석 주의
 6. 매개효과     a, b, c, c', 간접효과 ab, Sobel 검정, 부트스트랩 95% CI(난수 고정), 경로 그림
 7. 조절효과     X×W 상호작용, ΔR², 평균중심화 선택, 단순기울기(W 평균±1SD), 단순기울기 그래프
 8. 기준값 검산   교수자 기준결과 27개 항목과 앱 계산값 자동 비교
 공통           쉬운 한국어 오류 안내, 결과표 CSV 저장, 스마트폰용 세로 표 보기(사이드바),
                CSV 한글 인코딩(UTF-8/CP949) 자동 인식, 분석에 사용된 사례 수 표시

7. 분석 제한점
==================================================================
 · 결측값은 분석에 쓰는 변수 기준으로 해당 행을 통째로 제외합니다(listwise).
 · 회귀의 X는 숫자형만 받습니다. 범주형 X(더미 변수)는 지원하지 않습니다.
 · 이원분산분석은 모든 요인 조합(칸)에 사례가 2개 이상 있어야 합니다.
 · 매개·조절은 단순 모형(X 1개, M 또는 W 1개)만 지원하며, 공변량 통제는 없습니다.
 · 정규성·등분산 등 가정 검토는 일부(잔차 그래프, Levene)만 제공합니다.
 · 결과는 통계적 관계를 보여 줄 뿐 인과관계를 증명하지 않습니다.

8. 자주 생기는 문제
==================================================================
 'python'을 찾을 수 없음     → Python 재설치 시 "Add to PATH" 체크
 ModuleNotFoundError        → pip install -r requirements.txt 다시 실행
 .xls 파일이 안 열림          → xlrd 설치 확인, 또는 엑셀에서 .xlsx로 다시 저장
 CSV 한글이 깨짐             → 엑셀에서 "CSV UTF-8"로 저장
 스마트폰 접속 안 됨          → 같은 Wi-Fi/핫스팟 확인, 방화벽 허용, 또는 방법 B 사용
